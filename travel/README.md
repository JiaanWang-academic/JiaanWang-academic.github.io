# 我的足迹地图 · 点亮中国

一个纯前端的旅行足迹地图：点击地图点亮去过的城市，自动统计「已点亮 N 省 M 市」，并可导出分享图片。**数据完全存在你自己的电脑上**。


## 使用

双击 `index.html` 即可（无需服务器、无需联网）。
也可以用本地服务器打开（移动端访问更方便）：

```bash
python3 -m http.server 8777
# 浏览器打开 http://localhost:8777
```

## 功能

**点亮（默认二次确认，防误触）**
- 点击地图上的城市 → 该城市虚线高亮预览 + 右侧弹出确认条，**点「确认点亮」才真正生效**
- 确认方式三选一：点确认按钮 / 按 `Enter` / 再点一次同一个城市；取消用「取消」按钮或 `Esc`
- 待确认时切换画笔，确认按钮和预览颜色会跟着变
- 对已点亮的城市点击，确认条会变成「确认取消点亮」
- 嫌麻烦可勾选侧栏「点击地图直接点亮，不用确认」切回秒点模式（设置会记住）
- 四档状态：住过 / 去过 / 路过 / 想去（想去只进「想去清单」，不计入已点亮）
- 画笔快捷键 `1`~`5`

**选择与导航**
- 左侧「按省市选择」级联下拉框（按七大区分组），可定位、点亮该市、点亮整省、清空该省
- 顶部搜索框：输入城市名回车定位并进入待确认（支持「杭州」「杭州市」「浙江杭州」「大理」等写法）
- 「点亮该市 / 点亮整省 / 批量录入」属于明确操作，不需要二次确认（误操作可在提示条「撤销」）
- 三种视图：全国市级 / 全国省级（热力概览，点击省份下钻）/ 单省详图
- 滚轮缩放、拖拽平移，`⦿` 重置视角

**我在哪儿 · 按距离排序**
- 侧栏可填写常住城市（支持景点别名，如填「敦煌」会识别为酒泉）
- 填写后，**所有推荐都按离你的直线距离由近到远排序**，卡片上直接标出「📍距杭州 52 km」
- 不填则退回按推荐度排序；出发地会写入**导出备份**，换设备导入后自动恢复

**当季推荐 · 跟着时间走**
- 每座城市的「最佳季节」会被解析成月份，网站**按今天的月份**推荐该出发的地方
- 侧栏常驻「X月去哪儿」速览；图鉴首页就是 🔥 **当季推荐**，分三档：
  **🔥 本月正当时** → **📅 下月适合** → **⏳ 两月后适合**，方便提前一两个月订票
- **想去清单置顶**：你标过「想去」的地方一旦进入当季，会单独排在最前面提醒你「可以出发了」
- 顶部 🔥**当季**按钮：在地图上把本月当季、且你还没去过的城市高亮成暖橙色
- 图鉴里有 1-12 月的月份切换器，可以提前规划（比如 11 月就看明年 2 月去哪）
- 选完月份还可以**再选一个标签**（只能单选），比如「11 月 + 海滨」，再点一次取消筛选；
  标签后面的数字是该月当季的城市数
- 城市卡片、详情面板、地图悬浮提示都会显示「🔥11月正当时 / 📅12月可去」这样的时令角标

**旅行标签 · 图鉴**（顶部「🏷️ 标签图鉴」或快捷键 `T`）
- 内置 **189 座值得专程一去的城市**、**33 种旅行标签**（雪山 / 湖泊 / 草原 / 古城 / 石窟 / 美食 / 夜景…），
  每座城市还带一句话亮点、**5 星推荐度**和最佳季节；不值得专程跑的城市不打标签
- 推荐度分布：5★ 34 座（此生必去）· 4★ 45 · 3★ 49 · 2★ 41 · 1★ 20
- **我的标签**：按标签分组展示你已经点亮的城市 —— 一眼看出「我的雪山收集了几座」
- **全部推荐**：不分季节，只列没去过的，优先推荐**能解锁新标签**的城市，其次是高推荐度去处
- **全部标签**：按自然 / 人文 / 体验三类排布的进度格子，像集邮册一样看收集度
- 点任意标签 → 查看该标签下「已点亮 / 还没去」的全部城市；点城市卡片 → 直接飞到地图上那个位置
- 侧栏有标签云速览，地图悬浮提示和城市详情里也会显示标签与亮点
- 搜索框支持**景点名**：输「敦煌」「九寨沟」「喀纳斯」「稻城亚丁」会自动对应到所属城市（内置 212 条别名）

**记录**
- 每座城市可记录首次到访年份、评分（★）、旅行手记
- 自动统计：省份数、城市数、覆盖国土面积（万 km² 及占比）、七大区覆盖进度、旅行年历
- 足迹清单按省分组，点击任意城市可快速定位

**数据**
- 自动保存在浏览器 localStorage（键名 `china-travel-map:v1`）
- 导出 / 导入 JSON 备份（含出发地；可读清单里带标签、最佳季节和距出发地的距离）
- 批量录入：粘贴 `2023 北京 上海 杭州` 这样的文本一次点亮多城，支持行首年份
- 复制清单为文字、一键导出 PNG 分享图（2 倍清晰度，带「已点亮 N 省 M 市」标题）
- 误操作后，提示条里可以「撤销」

**其他**
- 浅色 / 深色主题
- 窄屏自适应（侧栏变抽屉）

## 目录结构

```
index.html              页面
css/style.css           样式
js/app.js               主逻辑
js/season.js            「最佳季节」文本 → 月份的解析工具
data/china-geo.js       离线地图数据（370 个地级行政区 + 省界 + 面积索引，约 2.9 MB）
data/city-tags.js       旅行标签库（33 标签 / 189 城 / 212 条景点别名，可自行增删）
vendor/echarts.min.js   ECharts 5.5.1（本地化，离线可用）
tools/build-map-data.mjs 地图数据构建脚本
tools/check-tags.mjs     标签库校验脚本
```

## 自定义标签库

`data/city-tags.js` 是纯数据文件，可以按自己的口味改：

```js
'黄山市': { t: ['世遗', '古村', '秋色'], s: 5, tip: '黄山云海 + 宏村西递', b: '4-5月 / 10-11月' },
//          标签（须在 tags 中定义）  推荐度1-5  一句话亮点            最佳季节
```

`b`（最佳季节）会被 `js/season.js` 解析成月份用于当季推荐，支持这些写法：
`6-9月`、`4-5月 / 9-10月`、`11-4月`（跨年）、`9月下旬-10月`、`10月`、`全年`。

改完跑一下校验，确认城市名能被识别、标签都已定义、季节都能解析：

```bash
node tools/check-tags.mjs
```

## 重新生成地图数据

行政区划调整后可重新构建（需要联网，数据源：阿里 DataV.GeoAtlas）：

```bash
node tools/build-map-data.mjs
```

脚本会下载各省边界、做 Douglas–Peucker 简化（省界 0.01°、市界 0.004°）、计算球面面积，
并输出 `data/china-geo.js`。下载结果缓存在 `.cache-geo/`，删除即可强制重新下载。

> 北京、天津、上海、重庆、香港、澳门、台湾按整体作为一个「市」统计，共 370 个地级单元。
